The idea

Rules tell Bob what's off-limits.
A permission makes sure of it. An auditor proves it.

# .bob/custom_modes.yaml  (computed from the project's poms)
- slug: uptake
  groups:
    - read
    - - edit
      - fileRegex: '<production source roots>/**.java'
    - mcp        # evidence + offline verifier
    - subagent   # explore only
  # no "execute": no shell, no -DskipTests

ImpossibleBench (ICLR 2026): when tests are read-only, agent test-gaming drops to near zero.

Uptake builds that finding into IBM Bob's own mode system: tests, pom.xml, .bob/ and ../ escapes are outside the edit permission, so Bob refuses those edits before any file is touched. An independent auditor checks anyway.

How it works

Reproduce → evidence → locked repair → proof

  1. 01

    Reproduce

    The real breaking upgrade replays in its original BUMP container, offline. Errors and failing tests become the work order.

  2. 02

    Evidence

    Uptake's MCP server tells Bob where each missing symbol lived, what replaced it, and what is on the classpath.

  3. 03

    Locked repair

    Bob in Uptake mode edits production code only, fans out explore subagents, or escalates with a proposed patch.

  4. 04

    Proof

    An auditor that trusts nothing rebuilds, classifies every change, proves proposals, and writes a re-verifiable receipt.

What it leaves in your repo: the fix, or a one-approval patch already proven green, plus UPGRADE_RECEIPT.md with a patch hash and uptake verify.

Real case · Log4Shell (CVE-2021-44228)

The Log4Shell upgrade broke 43 tests. Bob found why in one run.

Dependabot bumped log4j-core 2.12.1 → 2.15.0 but left log4j-slf4j18-impl at 2.12.1. LoggerContext fails at class load, and every test that logs dies after it.

Bob is not allowed to edit pom.xml, so it stopped and wrote the one-line fix as a proposal. Uptake applied it in a scratch copy:

✓ 67/67 tests green · one human approval

--- a/pom.xml
+++ b/pom.xml
   <artifactId>log4j-slf4j18-impl</artifactId>
-  <version>2.12.1</version>
+  <version>2.15.0</version>

# UPGRADE_RECEIPT.md
Verdict: ESCALATED
Proposed patch: proven green
Integrity violations: 0
